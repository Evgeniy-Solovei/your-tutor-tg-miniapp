Отдельных таблиц «на каждый класс» нет. Класс — поле Topic.grade_level. Mini App берёт задания ученика по его классу.

Как работает логика

Ученик (класс + цель)
    ↓
Трек (школа / аттестат 9 / ЦТ / ЦЭ)
    ↓
Разделы → Темы (grade_level = 1…11)
    ↓
Задания (Task) + варианты + эталон
    ↓
Ежедневная сессия в Mini App
  1. materials/russian/0N_klass/ — PDF учебников и сборников (файлы).
  2. python manage.py import_… — читает PDF / программу → пишет в БД.
  3. Тема привязана к классу. Задание висит на теме.
  4. Практика в приложении фильтрует темы по student.grade.

Команды наполнения (на сервере)

Запускать из корня проекта с активированным venv, папка materials/ должна быть на сервере.

{% for cmd, desc in commands %} {% endfor %}
КомандаЧто делает
python manage.py {{ cmd }} {{ desc }}

Где что править руками

  • Задания → раздел «Задания» (Task): вопрос, картинка, варианты, эталон.
  • Темы → «Темы»: название + класс (grade_level).
  • Треки → «Экзаменационные треки»: школа / ЦТ / ЦЭ / аттестат.
  • Ученики → приложение Students: класс и цель ученика.
